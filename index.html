Cómo se calcula
  • Días hábiles registrados: lunes a sábado con al menos un móvil cargado. Domingos, feriados y días aún no cargados no cuentan.
  • Ocupado: la celda tiene N° de ticket, obra o cliente, flete (TyG, Rackpar, Galvamax) o movimiento interno (planta, MV Itá, descarga de MP).
  • Taller: celda vacía pintada con el color de taller. S/C: celdas S/C, S/H o S/M. Disponible: celda vacía sin color de taller.
  • Ocupación = días ocupados ÷ días hábiles. Ocupación sin taller = días ocupados ÷ (días hábiles − días en taller).
  • Fuera del tablero: Móvil 84 (aún no incorporado) y los meses sin carga.

Instructivo rápido

Cómo usar el tablero, cargar los datos del día y sacar el informe. No hace falta instalar nada: el archivo se abre con doble clic en Chrome o Edge.

1Abrir y mirar el tablero

  1. Abrí el archivo Tablero_Ocupacion_Moviles_MV.html con doble clic.
  2. En la pestaña Tablero elegí arriba el Año y el Mes. Con "Todo el año" ves el año completo.
  3. Para ver un grupo, elegí el Tipo de móvil (Scania, Scania con Muck, Grúas, Livianos) o tocá su tarjeta.
  4. Para ver un solo móvil, elegilo en Móvil o tocá su tarjeta del semáforo. Ver toda la flota quita el filtro.
  5. Pasá el mouse por las barras, puntos y celdas para ver el detalle (ticket, obra, días).

2Qué significa cada color

  • Ocupado = obra/cliente, ticket, flete o interno.
  • Semáforo: verde 70% o más · amarillo 40 a 69% · rojo menos de 40% · gris si pasó la mitad del período en taller.
  • Solo cuentan los días de lunes a sábado que tienen carga. Domingos, feriados y días futuros no cuentan.

3Cargar el día (Pincel)

  1. Andá a la pestaña Cargar y editar y elegí el mes arriba.
  2. Dejá el modo en Pincel.
  3. Elegí qué cargar: Obra / cliente, Ticket, Flete, Interno, S/C, Taller o Disponible (para borrar).
  4. Escribí el N° de ticket o el nombre de la obra en el recuadro de al lado (las obras se autocompletan).
  5. Tocá la celda del móvil y el día, o arrastrá para pintar varios días seguidos.

4Cargar varios días de un móvil

  1. En Cargar y editar cambiá el modo a Editar celda.
  2. Tocá el primer día. Se abre un recuadro.
  3. Elegí el Estado, escribí el ticket u obra y poné "Aplicar hasta el día".
  4. Dejá tildado Saltear domingos y tocá Aplicar.

¿Te equivocaste? ↶ Deshacer o Ctrl + Z.

5Empezar un mes nuevo

  1. En Cargar y editar, en Nuevo mes elegí el mes (viene propuesto el siguiente).
  2. Tocá Crear mes: aparece la grilla vacía con todos los móviles en flota.
  3. Cargá los días como en los pasos 3 y 4.

6Taller y flota

  • Referencias de taller: elegí el móvil, escribí el motivo (ej. "reparación de embrague") y tocá Agregar. Sale en el tablero y en el informe.
  • Flota: cambiá la capacidad o el tipo de un móvil, destildá En flota si sale de servicio, o sumá uno nuevo con Agregar móvil.

7Guardar y compartir

  • Cada cambio se guarda solo en este navegador (arriba ves la hora del último guardado). Guardar lo fuerza.
  • Guardar como archivo: descarga una copia del tablero con todo lo cargado. Usala para pasarla a otra computadora o como respaldo.
  • Exportar a Excel (en Cargar y editar): saca la planilla de Logística con una hoja por mes.
  • Generar para GitHub: descarga index.html, la versión de consulta para celulares. En GitHub: abrí el repositorio → Add file → Upload files → arrastrá el index.html → Commit changes. Reemplaza al anterior y en 1 o 2 minutos el link muestra los datos nuevos. Con la sincronización automática (paso 10) esto se hace una sola vez.

8Cargar desde Excel

  • Si Logística sigue usando la planilla OCUPACIÓN DE MÓVILES, tocá Cargar Excel y elegí el archivo. El tablero se arma solo.
  • El taller se lee por el color de la celda o por la palabra TALLER. Los móviles se leen de la columna "Móvil".
  • Datos originales vuelve a los datos que venían en el archivo (borra lo cargado en este navegador).

9Informe ejecutivo

  1. Elegí arriba el período (mes o año) y, si querés, un tipo de móvil.
  2. Abrí la pestaña Informe ejecutivo: se arma solo con indicadores, tablas, gráficos y alertas.
  3. Escribí tus comentarios en Observaciones de Gerencia.
  4. Imprimir / guardar PDF para presentarlo, o Descargar informe para mandarlo por correo.

10Sincronización automática (se configura una sola vez)

Con Firebase (console.firebase.google.com → proyecto Moviles-mv):

  1. Compilación → Firestore Database → Crear base de datos: ubicación southamerica-east1 (São Paulo), modo producción.
  2. En Firestore, pestaña Reglas: pegá el contenido de firestore_reglas.txt, poné tu correo en la lista y tocá Publicar.
  3. Compilación → Authentication → Comenzar → pestaña Método de acceso → habilitá Correo electrónico/contraseña. Después en Usuarios → Agregar usuario creá tu correo y una contraseña (y uno por cada persona que cargue, agregándola también a la lista de las reglas).
  4. Engranaje → Configuración del proyecto → General: copiá el ID del proyecto (moviles-mv) y la Clave de API web.

Con Supabase: corré supabase_moviles.sql en SQL Editor, creá el usuario en Authentication → Users y copiá Project URL y clave anon desde Project Settings → API.

En el tablero de la PC: Cargar y editar → Sincronización automática → elegí Firebase o Supabase, pegá los datos, tu correo y contraseña → Conectar. Desde ahí cada cambio se sube solo (arriba ves "☁ En línea").

Para los celulares: tocá Generar para GitHub y subí ese index.html a GitHub una sola vez. La página lee los datos en vivo cada vez que se abre y se refresca sola cada minuto.

Si cargan dos PCs: al abrir el tablero trae lo último de la nube; Traer de la nube lo fuerza. Nunca compartas la contraseña; la clave de API sí puede ir en la página porque las reglas solo permiten leer.

Importante: sin la sincronización del paso 10, lo cargado queda guardado solo en el navegador de esta computadora. Si se borra el historial del navegador o se cambia de computadora, se pierde. Al terminar cada semana hacé Guardar como archivo (o Exportar a Excel) y guardalo en la carpeta compartida de Logística. Si varias personas cargan, que trabajen siempre sobre la última copia guardada.
